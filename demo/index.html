玉米设计语言

纸田青釉的底色、墨绿近黑的文字、一抹玉米黄。 宋体负责标题，黑体负责正文，等宽体负责数据——克制、有秩序、认得出来。

Principles

三句话说清这套语言

01

颜色从田里来

纸、青釉、墨、玉米黄、苞叶绿。不引入第七种色相，maize 是唯一强点缀。

02

字体有分工

serif 标题、sans 正文、mono 数据与标签。eyebrow 小方块是签名细节。

03

形状要克制

2–4px 小圆角、细边框、浅阴影。hover 浮起 + maize 描边是签名交互。

Start

两个文件，零构建

组件层是纯 CSS + HTML 片段：拷进项目即用，没有构建依赖。 

<!-- 1. 先 tokens，再组件层 -->
<link rel="stylesheet" href="corn-tokens.css">
<link rel="stylesheet" href="corn.css">

<!-- 2. 用 .corn- 类搭建 -->
<button class="corn-btn corn-btn-maize">保存</button>
