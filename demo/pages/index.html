Principles

三句话说清这套语言

01

颜色从田里来

纸、青釉、墨、玉米黄、苞叶绿。不引入第七种色相，maize 是唯一强点缀。

02

字体有分工

serif 标题、sans 正文、mono 数据与标签。eyebrow 小方块是签名细节。

03

动效有目的

浮起 1–2px、maize 描边光、短促的勾选与滑动；减少动效时全部收敛。

Start

两个文件起步，一个脚本可选

组件层是纯 CSS + HTML 片段，拷进项目即用；需要交互（标签页、菜单、弹窗、通知）再加 corn.js。

index.html 
<link rel="stylesheet" href="corn-tokens.css">
<link rel="stylesheet" href="corn.css">
<script src="corn.js" defer></script>

<body class="corn-body">
  <button class="corn-btn corn-btn-maize">保存</button>
</body>
