# Corn UI 评审清单

> 用法：对照真实渲染画面逐项过。每项给"过/不过 + 证据"，不空泛打分。

## 语言一致性

- [ ] 所有颜色都能在 token 表里找到出处；没有一次性自造色值。
- [ ] 纸面阶梯方向正确：背景 ≤ 面板 ≤ 更深区域，没有用反。
- [ ] `maize` 用量克制：eyebrow 方块、selection、focus、至多一处主强调；没拿它铺大背景。
- [ ] serif 只出现在标题级位置；mono 只出现在数据/标签位置。
- [ ] 圆角在 2–9px 阶梯内；没有 pill 按钮或大圆角卡片（9px 是大卡片上限）。
- [ ] 深色区块用的是 `ink` 系，没有引入蓝黑、纯黑或新深色。

## 层级与排版

- [ ] 每屏有且只有一个视觉主角；次要元素没有抢戏。
- [ ] 标题层级清楚（h1→h2→h3 不跳级），行长 52–60 字符以内。
- [ ] eyebrow 用对地方（区块级标记），没有拿来当段落强调。
- [ ] 数字用 tabular-nums/mono；时间戳、路径、版本号用 mono。

## 交互与状态

- [ ] 所有可点元素有 hover；按钮 hover 浮起 1px 且颜色在 token 内变化。
- [ ] `:focus-visible` 描边可见（浅底 maize-deep，深底 maize）。
- [ ] 禁用、加载、空、错误四态有设计；空状态用 `corn-empty` 模式（虚线框 + serif 标题）。
- [ ] 卡片 hover 出现 maize 描边光——签名交互没有被覆盖掉。

## 响应式

- [ ] 360–430px 无横向滚动；`--corn-gutter` 的 clamp 生效。
- [ ] 触控目标 ≥ 40px（btn-sm 40px 起步）。
- [ ] 深色区块在窄屏下内边距与节奏仍成立。

## 输出

评审结论按「必须改 / 建议改 / 可选」三档列出，每条附截图位置或元素选择器作为证据；没有证据的项标记为"未检查"而不是默认通过。
